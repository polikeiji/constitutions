# Bicep naming convention

The Azure Cloud Adoption Framework naming convention every resource deployed via Bicep is
built from.

| Document | Covers |
|---|---|
| [The naming pattern](naming-convention-pattern.md) | The pattern itself, and the environment and region tokens |
| [Abbreviations](naming-convention-abbreviations.md) | The CAF abbreviation per resource type, and applying the pattern in a template |

The rule numbers run continuously across the two files: the pattern is rules 1–3 with its
hyphen exception, and the implementation rules pick up at 4.
